Web client for BCKash.Api.

## Getting Started

1. Run `npm install`
2. Copy `.env.example` to `.env`
3. Update `VITE_API_BASE_URL` in `.env` to point at your BCKash.Api instance
4. Run `npm run dev`

## Environment Variables

- `VITE_API_BASE_URL`: Base URL for BCKash.Api requests
- `VITE_API_TIMEOUT_MS`: Axios timeout in milliseconds
